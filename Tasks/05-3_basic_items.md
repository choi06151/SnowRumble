# Task 05-3 - MVP 기본 아이템

## 설명

선물상자에서 획득하는 아이템 중 MVP에 포함할 최소 목록을 확정하고, 인벤토리 없이 즉시 사용하거나 착용하는 기본 흐름을 만든다.

## 구현 항목

- [ ] 구현 전에 MVP 기본 아이템 목록을 사용자와 확정한다.
- [ ] 아이템을 사용형과 착용·장비형으로 구분한다.
- [ ] 선물상자 보상을 플레이어가 획득할 수 있다.
- [ ] 사용형 아이템은 획득 또는 상호작용 시 정해진 효과를 적용한다.
- [ ] 착용·장비형 아이템은 해당 플레이어의 상태에 효과를 적용한다.
- [ ] 아이템 획득과 효과가 서버 권한으로 판정되고 필요한 참가자에게 반영된다.

## 메인 프로그래머 책임

- 확정된 MVP 아이템의 획득·사용·장착·효과, 아이템 Blueprint, 모델·장착 위치와 비UI 사용 표현을 완성한다.
