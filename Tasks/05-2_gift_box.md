# Task 05-2 - 선물상자

## 설명

경기 중 선물상자가 생성되고 눈 공격을 받으면 개봉되어 등급에 맞는 보상을 제공할 수 있게 한다.

## 구현 항목

- [ ] 서버가 경기 중 선물상자를 생성할 수 있다.
- [ ] 선물상자는 파랑, 빨강, 금색 등급을 구분한다.
- [ ] 플레이어에게 피해를 줄 수 있는 공격이 적중하면 상자가 개봉된다.
- [ ] 한 선물상자가 중복 개봉되지 않는다.
- [ ] 상자 등급에 맞는 보상 후보에서 결과를 결정할 수 있다.
- [ ] 생성, 개봉, 보상 결과가 모든 참가자에게 동일하게 보인다.

## 메인 프로그래머 책임

- 서버의 상자 생성·등급·공격 판정·중복 방지·보상 결정과 등급별 상자 Blueprint 및 비UI 개봉 표현을 완성한다.

## SUB UI 인계

- 연계 SUB Task: `Tasks/S05-2_item_status_ui.md`
- 로컬 플레이어가 획득한 보상 결과를 UI가 표시할 수 있는 이벤트로 제공한다.

## 범위 밖

- 산타가 상자를 흩뿌리는 최종 연출
- 모든 아이템 기능
