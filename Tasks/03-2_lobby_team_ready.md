# Task 03-2 - 대기방 팀 선택과 준비

## 설명

LAN 세션 참가자들이 대기방에서 서로를 확인하고 팀을 선택한 뒤 준비 상태를 공유할 수 있게 한다.

## 구현 항목

- [ ] 접속한 플레이어 목록 상태를 서버가 관리하고 복제한다.
- [ ] 플레이어가 이름과 팀 색상 변경을 서버에 요청할 수 있다.
- [ ] 플레이어가 준비와 준비 해제를 서버에 요청할 수 있다.
- [ ] 대기방 상태가 모든 참가자에게 동일하게 복제된다.
- [ ] 호스트의 경기 시작 가능 여부를 서버가 판정한다.

## 메인 프로그래머 책임

- 접속자, 이름, 팀, 준비 상태와 경기 시작 가능 조건을 서버 권한 및 복제 상태로 완성한다.
