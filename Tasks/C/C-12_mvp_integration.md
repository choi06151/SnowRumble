# Task C-12 - MVP 통합

## 설명

네 역할의 완료 결과를 1vs1~4vs4, 3판 2선승 전체 흐름으로 통합하고 새 MVP의 최종 상태를 검증한다.

## 상태 전이 기준
- 시작 가능: C-02~C-11, K-10, S-12, J-05 완료
- 완료 가능: 모든 수동 작업과 호스트·클라이언트·최대 인원 결과를 사용자가 확인

## 구현 항목
- [ ] 메인 로비부터 대기방 복귀까지 전체 흐름을 통합한다.
- [ ] 세 맵의 랜덤 라운드와 3판 2선승을 확인한다.
- [ ] 플레이어, 눈 전투, 아이템, 환경, UI와 모델 계약을 점검한다.
- [ ] 양 팀 동수와 최대 4vs4에서 서버 권한·복제 결과를 확인한다.
- [ ] 남은 구조 의심과 레거시 참조를 정리한다.

## 작업 배정
- 담당자·기능·계약 소유자: 최재원(C)
- 자산 수정자·생성·변경 후보: 통합 승인 전 확정
- 공유 확인 대상: K, S, J 전원
- 병합 순서: 공용 계약 → K 아이템 → J·S 맵 → S UI·아트 → 최종 통합

## 공용 계약과 인계

- 제공할 계약: 최종 MVP 기준선과 남은 후속 항목
- 인계 대상: 전원
