# Task C-13 - 핫팩 부활 계약

## 설명

얼음 상태의 아군을 일반 핫팩으로 10초 동안 부활시키고, 황금 핫팩이 팀 부활을 요청할 수 있는 서버 권한 계약을 제공한다.

## 상태 전이 기준

- 시작 가능: C-06, C-07 완료
- 완료 가능: 부활 진행·취소·완료와 K-07·S-07 인계 확인

## 구현 항목

- [ ] 일반 핫팩 부활 대상, 거리와 팀 조건을 서버가 검사한다.
- [ ] 10초 부활 진행, HP 50% 복귀와 3초 무적 결과를 제공한다.
- [ ] 이동·공격·키 해제·거리 이탈·넉백에 따른 부활 취소 결과를 제공한다.
- [ ] 마지막 생존자가 먼저 얼면 진행 중 부활과 관계없이 패배하는 C-06 결과를 보존한다.
- [ ] 황금 핫팩이 허용된 팀원을 즉시 부활시키는 요청 지점을 제공한다.

## 작업 배정

- 담당자·기능·계약 소유자: 최재원(C)
- 자산 수정자·생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: K-07, S-07, C-05
- 병합 순서: C-06·C-07 후, K-07·S-07 전

## 공용 계약과 인계

- 제공받을 계약: C-06 얼음·사망 상태, C-07 회복·무적 계약
- 제공할 계약: 부활 시작·진행·취소·완료 요청과 상태 이벤트
- 인계 대상: K-07, S-07, C-05

## 범위 밖

- 부활 UI와 모델 표현

- 황금 핫팩 사용자 본인도 효과 대상인지
