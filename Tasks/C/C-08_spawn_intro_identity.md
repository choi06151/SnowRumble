# Task C-08 - 팀 식별 데이터

## 설명

## 상태 전이 기준
- 시작 가능: C-03 완료
- 완료 가능: 닉네임·팀 색·표시 상태와 S-05 인계 확인

## 구현 항목

- [ ] 이름표가 읽을 생존·관전 표시 보조 상태를 제공한다.
