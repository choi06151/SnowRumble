# Task C-08 - 팀 등장과 식별 데이터

## 설명

무작위 맵에서 팀별 시작 지점에 생성하고 처음 5초 동안 행동을 제한하며 팀 색과 닉네임 데이터를 표현 파트에 제공한다.

## 상태 전이 기준
- 시작 가능: C-03 완료, 맵별 팀 시작 지점 준비
- 완료 가능: 서버 스폰·행동 제한과 S-05 인계 확인

## 구현 항목
- [ ] 서버가 팀에 맞는 시작 지점을 선택한다.
- [ ] 라운드 시작 5초 동안 이동과 전투 행동을 제한한다.
- [ ] 로컬 카메라가 팀원을 보여줄 시작·종료 상태를 제공한다.
- [ ] 닉네임과 팀 색을 머리 위 UI가 읽을 수 있게 제공한다.

## 작업 배정
- 담당자·기능·계약 소유자: 최재원(C)
- 자산 수정자·생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: S-05, S-10, J-02, J-04
- 병합 순서: C-03 후, 맵 게임플레이 배치와 S-05 전

## 공용 계약과 인계
- 제공받을 계약: C-03 팀 상태, 맵별 시작 지점
- 제공할 계약: 스폰 결과, 시작 제한, 팀 소개와 닉네임·팀 색
- 인계 대상: S-05, S-10, J-02, J-04

## 범위 밖
