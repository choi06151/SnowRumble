# Task C-09 - 눈 전투 완성

## 설명

기존 눈 제작·획득·조준·투척·굴리기 흐름을 보존하고 큰 눈 광역 피해까지 새 공용 효과 계약에 연결한다.

## 상태 전이 기준
- 시작 가능: C-01, C-07 완료
- 완료 가능: 작은 눈과 큰 눈의 호스트·클라이언트 결과 및 S-06 인계 확인

## 구현 항목
- [ ] 기존 눈 제작·획득·내려놓기와 조준·투척 흐름을 재검증한다.
- [ ] 좌클릭·우클릭·E·G가 눈 제작, 줍기, 굴리기, 투척, 장비 공격, 부활, 상자 열기 사이에서 충돌하지 않도록 입력 행동 우선순위 계약을 정리한다.
- [ ] 굴리기 성장·충돌과 큰 눈 운반·투척의 남은 결과를 확인한다.
- [ ] 큰 눈 충돌 지점 주변에 서버 권한 광역 피해·넉백을 적용한다.
- [ ] 작은 눈 기본 피해 10과 큰 눈 기본 피해 35 기준을 반영한다.

## 작업 배정
- 담당자·기능·계약 소유자: 최재원(C)
- 자산 수정자·생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: S-06, K-02, K-05, K-06, K-07
- 병합 순서: C-01·C-07 후, C-12 전

## 공용 계약과 인계
- 제공받을 계약: C-07 피해·보정 계약
- 제공할 계약: 눈 제작·조준·충전·보유·피격 상태와 입력 행동 우선순위
- 인계 대상: S-06, K-02, K-05, K-06, K-07
