# Task C-09 - 눈 전투 완성

## 설명

완전히 성장한 큰 눈덩이는 바닥 또는 플레이어 충돌 후 물리 굴리기로 전환한다. 굴러가는 동안 이동 거리에 따라 크기가 감소하고, 플레이어에게 피해와 진행 방향 넉백을 적용한다. 벽 충돌 또는 완전 소멸 시 충돌 이펙트 후 제거한다.

기존 눈 제작·획득·조준·투척·굴리기 흐름을 보존하고 큰 눈 광역 피해까지 새 공용 효과 계약에 연결한다.

## 상태 전이 기준
- 시작 가능: C-01, C-07 완료
- 완료 가능: 작은 눈과 큰 눈의 호스트·클라이언트 결과 및 S-06 인계 확인

- [ ] 기존 눈 제작·획득·내려놓기와 조준·투척 흐름을 재검증한다.
- [x] 눈 제작 trace가 중간 동적 액터에 막혀도 뒤쪽 `SnowSurface` 표면을 찾을 수 있게 한다.

- [ ] 좌클릭·우클릭·E·G가 눈 제작, 줍기, 굴리기, 투척, 장비 공격, 부활, 상자 열기 사이에서 충돌하지 않도록 입력 행동 우선순위 계약을 정리한다.

- [x] 차징 또는 투척 AnimNotify 대기 중 피격되어 연출이 끊겨도 손에 든 눈덩이를 다시 던질 수 있게 상태를 복구한다.
- [x] 눈덩이를 굴리는 동안 굴리는 눈덩이의 outline과 상호작용 안내를 숨긴다.

- [x] 낙하 큰 눈덩이가 플레이어와 충돌하면 서버에서 기본 피해 50을 적용한다.
- [x] 낙하 큰 눈덩이는 플레이어 충돌 후 계속 낙하하고, 지면에 닿으면 `Ground` 상태로 정착해 즉시 획득 가능하게 한다.
- [x] 낙하 큰 눈덩이를 기본 `0.25초` 간격의 서버 타이머로 순차 생성해 유성우처럼 연출한다.
- [x] 낙하 큰 눈덩이에 랜덤 수평 속도를 부여하고, 착지 후 물리 시뮬레이션으로 경사면을 굴러가게 한다.

## 기존 구현 인수
- `USnowballCreationComponent`가 `SnowSurface` 태그, 제작 진행도, 서버 생성 요청과 `SnowballItemClass`를 담당한다.
- `USnowballEquipmentComponent`가 획득, 보유, 조준, 충전, 내려놓기, 굴리기 서버 요청과 복제 상태를 담당한다.
- `ASnowballItem`이 `Ground`, `Rolling`, `Held`, `Thrown` 상태, 성장, 투척 충돌, 직접 피해·넉백과 `PlayImpactEffect` Blueprint 이벤트를 담당한다.
- `ASnowRumbleCharacter`에는 `SnowballHoldPoint`, `SnowballSocket` 부착, `RollingSnowballCollision`, 조준 카메라와 HUD 연결 지점이 있다.
- `ASnowballProjectile`은 현재 `Source` 사용처가 없는 레거시 클래스다. 참조 확인 전 삭제하지 않고, 현재 플레이 파이프라인은 `ASnowballItem` 기준으로 유지한다.
- 기존 피해 기본값은 작은 눈 25 기반으로 남아 있으므로 새 기준 작은 눈 10, 큰 눈 35와 큰 눈 광역 효과를 C-07 계약에 맞춰 수정해야 한다.

## 수동 작업 (구현 후 구체화)
- 눈덩이 생성 직후 바닥 아래로 꺼지는 현상을 막기 위해 `ASnowballItem` Ground 상태는 물리 낙하 대신 서버가 확인한 표면 위치에 고정한다.
- `USnowballCreationComponent`는 제작 완료 시 눈 표면 hit normal과 눈덩이 반지름으로 생성 위치를 보정하고, 내려놓기·굴리기 종료는 현재 위치 아래 trace로 다시 바닥에 스냅한다.
- `BP_SnowballItem`류에서 `Grounding` 카테고리의 `GroundSettleTraceUpDistance`, `GroundSettleTraceDownDistance`, `GroundSettleExtraClearance`를 맵 지형 높낮이에 맞게 미세 조정할 수 있다.

## 변경 기록

- 2026-08-21: 충전 중 우클릭 release 입력을 기존 좌클릭 release와 같은 `USnowballEquipmentComponent::ReleaseChargedSnowball()` 경로로 연결했다. 우클릭 조준을 먼저 떼도 서버 검증된 충전 투척 요청이 실행되고, 기존 AnimNotify 기반 실제 발사 흐름을 유지한다.
- 2026-08-22: AnimNotify 기반 투척에서 입력 release 후 카메라를 돌리면 예전 방향으로 발사되던 문제를 수정했다. 서버 pending throw에는 속도·충전량만 유지하고, Notify 시점에 로컬 카메라 위치·방향을 다시 보내 서버 trace로 최종 투척 방향을 계산한다.
- 2026-08-23: 차징 또는 AnimNotify 대기 중 피격 반응으로 던지기 연출이 끊기면 `bHasPendingThrow`가 남아 손에 눈덩이가 있어도 다시 던질 수 없던 문제를 수정했다. 실제 피해가 적용되면 서버가 보유 눈덩이는 유지하고 충전/보류 투척 상태만 정리한다.
- 2026-08-23: PvP 중 눈 제작이 간헐적으로 시작되지 않는 문제를 줄이기 위해 제작 표면 탐색을 단일 hit trace에서 multi hit trace로 변경했다. 캐릭터와 부착 액터는 무시하고, trace 결과 중 가까운 `SnowSurface` 태그 액터를 제작 표면으로 사용한다.
- 2026-08-26: QA에서 눈 제작이 간헐적으로 시작되지 않는 원인을 확인할 수 있도록 서버 제작 시작·완료 검증에 `Creating`, `Frozen`, `Aiming`, 눈덩이 보유, `SnowballItemClass`, 카메라 원점 거리, `SnowSurface` hit/tag 상태 로그를 추가했다. 게임 동작은 변경하지 않았다.
- 2026-08-23: 눈덩이를 굴리는 동안 굴리는 눈덩이를 outline/상호작용 안내 후보로 잡지 않게 했다. 굴리기 종료 후 바닥 상태가 되면 기존처럼 다시 후보가 된다.
- 2026-08-24: `ASnowballItem::HandleThrownImpact()`에서 투척자와 피격 캐릭터의 `LobbyTeam`을 서버 비교해 같은 팀이면 눈덩이 피해와 넉백을 무시하고 충돌 이펙트와 눈덩이 제거만 유지하게 했다.
- 2026-08-24: `ASnowballItem` 투척 피해에 `GrowthProgress` 기반 성장 배율을 추가했다. 기본 크기는 기존 피해를 유지하고, 최대 성장 시 기본 3배까지 증가하며 차지 배율과 함께 서버에서 계산한다.
- 2026-08-24: 공중에서 작은 눈덩이를 던지는 경우 `USnowballEquipmentComponent`가 서버 release 시점의 `ASnowRumbleCharacter::IsInAir()`를 기준으로 `AirborneThrowDamageMultiplier` 기본 1.5와 `AirborneThrowSpeedMultiplier` 기본 1.2를 pending throw에 저장한다. `ASnowballItem::Throw()`는 전달받은 피해 배율을 충돌 시 최종 피해에 곱한다. `git diff --check`, UHT, C++ 컴파일과 `.lib` 생성은 통과했고, 최종 DLL 링크는 실행 중인 Unreal Editor의 DLL 잠금 `LNK1104`로 보류됐다.
- 2026-08-26: 선물상자와 동일한 서버 타이머에서 NavMesh에 투영된 위치를 기준으로 완전 성장 큰 눈덩이를 기본 10개 낙하시킨다. `FallingSnowballClass`, 개수, NavMesh 분산 반경, 낙하 높이와 피해량은 GameMode 인스턴스에서 조정할 수 있으며, 낙하 눈덩이의 플레이어 충돌 피해 기본값은 50이다.
- 2026-08-26: 낙하 큰 눈덩이는 공중 플레이어 충돌 시 피해만 적용하고 낙하를 재개하며, 지형 충돌 시 굴리기 없이 `Ground` 상태로 정착해 기존 `E - 눈덩이` 획득 흐름을 사용하도록 변경했다.
- 2026-08-26: 낙하 큰 눈덩이 10개를 한 프레임에 일괄 생성하지 않고, `FallingSnowballSpawnIntervalSeconds` 기본 0.25초 간격으로 순차 생성하도록 유성우 타이머를 추가했다.
- 2026-08-26: 낙하 큰 눈덩이마다 랜덤 수평 속도와 방향을 부여했다. 지형 충돌 뒤에는 물리 시뮬레이션을 유지하고, 속도가 낮아진 뒤 `Ground` 상태로 정착해 획득 가능하게 한다.
- 2026-08-26: 선물상자와 큰 눈덩이를 동시에 생성하지 않고 교대 이벤트 타이머로 분리했다. 첫 이벤트는 선물상자이며, 이후 느림·보통·빠름별 기본 간격을 30초·20초·10초로 설정해 큰 눈덩이와 번갈아 생성한다.
- 2026-08-26: 교대 이벤트의 개인 텍스트 알림을 이벤트별 WBP 슬롯으로 교체했다. `GiftBoxAnnouncementWidgetClass`와 `FallingSnowballAnnouncementWidgetClass`를 지정하면 각 클라이언트가 `FadeInOutAnimation`을 재생하고 기본 3초 후 위젯을 제거한다.
