# Task C-07 - 플레이어 효과 공용 계약

## 설명

K의 아이템과 S·J의 맵 환경이 플레이어 내부 상태를 직접 수정하지 않고 피해·회복·무적·능력 보정을 요청할 공용 계약을 제공한다.

## 상태 전이 기준
- 시작 가능: C-06 완료
- 완료 가능: 각 효과의 서버 검증 계약과 K·S·J 인계 확인

## 구현 항목
- [ ] 피해, 회복과 무적 적용을 서버가 검증하는 공개 계약을 제공한다.
- [ ] 이동속도·받는 피해·눈 제작 속도·눈 피해 보정 계약을 제공한다.
- [ ] 맵 환경이 플레이어 내부 HP를 직접 쓰지 않고 지속 피해를 요청하게 한다.
