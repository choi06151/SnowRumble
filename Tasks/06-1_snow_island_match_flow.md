# Task 06-1 - 눈 쌓인 섬과 경기 흐름

## 설명

눈 쌓인 섬에서 팀 단위 PvP 경기를 시작하고, 얼음물로 전투 영역을 제한하며 한 팀 전원이 얼면 승패를 확정할 수 있게 한다.

## 구현 항목

- [ ] MVP 눈 쌓인 섬 맵에서 팀별 시작 위치를 구분한다.
- [ ] 경기 시작 시 참가자를 선택한 팀으로 배치한다.
- [ ] 얼음물이 플레이어에게 피해를 주고 플레이 영역을 제한한다.
- [ ] 시간 경과에 따른 영역 축소 흐름을 확인할 수 있다.
- [x] 각 플레이어는 자신의 로컬 카메라에서만 눈 내리는 환경 VFX를 본다.
- [ ] 한 팀의 모든 플레이어가 동시에 얼었는지 서버가 판정한다.
- [ ] 승리 팀과 패배 팀을 모든 참가자에게 동일하게 알린다.

## 메인 프로그래머 책임

## 현재 로컬 눈 VFX 구현 결과

- `ASnowRumbleCharacter`의 `LocalSnowEffect` Niagara Component는 `FollowCamera`에 부착된다.
- `BeginPlay()`와 `PawnClientRestart()`에서 로컬 조종 캐릭터인지 확인하고, 자기 캐릭터의 눈 VFX만 활성화한다.
- 원격 플레이어 캐릭터의 `LocalSnowEffect`는 비활성화하고 `Only Owner See`를 함께 적용해 다른 플레이어 화면에 표시하지 않는다.
- 눈 VFX 상태는 네트워크로 복제하지 않고 각 컴퓨터가 자신의 로컬 캐릭터를 기준으로 결정한다.

## 수동 작업

1. `BP_SnowRumbleCharacter`를 열고 Components의 `LocalSnowEffect`를 선택한다.
2. `Niagara System Asset`에 `Content/VFX/NS_Snow`를 지정한다.
3. 카메라 주변에서 눈이 자연스럽게 보이도록 `LocalSnowEffect`의 상대 위치와 `NS_Snow`의 생성 범위·밀도·속도를 조정한다.
