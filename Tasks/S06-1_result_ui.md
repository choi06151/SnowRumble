# SUB UI Task S06-1 - 경기 결과 UI

## 설명

경기 종료 시 로컬 플레이어 관점의 승리·패배 결과를 표시하고 메인 프로그래머가 제공한 다음 흐름 요청을 실행할 수 있게 한다.

## 구현 항목

- [ ] 경기 종료 시 승리와 패배 결과를 구분해 표시한다.
- [ ] 결과 화면이 중복으로 생성되지 않는다.
- [ ] 메인 Task에서 허용한 다음 흐름 요청 UI를 제공한다.
- [ ] 다음 흐름 요청의 진행 또는 실패 상태를 표시한다.
- [ ] UI가 승패와 이동 가능 여부를 자체 판정하지 않는다.

## 범위 밖

- 승패 판정과 경기 상태 변경
- 레벨 이동과 세션 흐름 구현
- 최종 출시 수준의 UI·사운드 폴리싱

## 사전 전제

- Main Task 06-1의 승패와 경기 종료 상태
- Main Task 06-2의 다음 흐름 요청과 결과 이벤트

## 작업 배정

- 담당자: SUB 프로그래머
- 선점 UI 자산: Main Task 인계 후 확정

- 반영 순서: Main Task 06-1과 06-2의 UI 연결 지점 완료 후 시작
