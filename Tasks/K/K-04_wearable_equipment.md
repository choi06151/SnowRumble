# Task K-04 - 착용 장비

## 설명

부츠·패딩·장갑의 소유와 능력 보정을 서버가 관리하고 장비 외형과 UI가 읽을 상태를 제공한다.

## 상태 전이 기준
- 시작 가능: K-01 완료
- 완료 가능: 세 장비 보정과 S-08·S-09 인계 확인

## 구현 항목
- [ ] 부츠가 이동속도 10% 증가를 적용한다.
- [ ] 패딩이 받는 피해 10% 감소를 적용한다.
- [ ] 장갑이 눈 제작 속도 15% 증가를 적용한다.
- [ ] 장비 소유·교체 상태를 서버가 확정하고 복제한다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: K 아이템, C 플레이어 효과 계약
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-07, S-08, S-09
- 병합 순서: K-01 후, S-08 연결과 K-10 전

## 공용 계약과 인계
- 제공받을 계약: C-07 능력 보정 계약
- 제공할 계약: 장비 슬롯·소유·외형 상태
- 인계 대상: S-08, S-09

## 범위 밖
- 장비 모델과 외형 부착 작업

## 사전 전제
- K-01
- C-07

## 결정 필요
- 같은 장비 중복 획득과 교체·드롭 방식
