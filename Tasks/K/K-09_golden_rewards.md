# Task K-09 - 황금 보상

## 설명

마지막 금색 상자의 황금 핫팩·눈삽·눈오리 제작기·붕어빵 후보와 역전용 보상 결과를 통합한다.

## 상태 전이 기준
- 시작 가능: K-02, K-03, K-05, K-06, K-07 완료
- 완료 가능: 금색 후보 풀·지급·효과와 S-09 인계 확인

## 구현 항목
- [ ] 마지막 금색 상자가 확정 후보 중 하나만 지급한다.
- [ ] 각 황금 아이템이 개별 Task에서 정의한 효과와 상태를 사용한다.
- [ ] 같은 플레이어의 중복 황금 장비 획득을 서버가 처리한다.
- [ ] 보상 결과를 전체 참가자 안내와 UI에 제공한다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: 강혜원(K), 경기 시점은 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-05, S-09
- 병합 순서: 관련 개별 아이템 후, K-10 전

## 공용 계약과 인계
- 제공받을 계약: C-05 금색 상자 시점, 관련 아이템 Task
- 제공할 계약: 금색 보상 후보·지급·안내 결과
- 인계 대상: S-09, K-10

## 범위 밖
- 새 황금 아이템 추가

## 사전 전제
- K-02, K-03, K-05, K-06, K-07

## 결정 필요
- 중복 황금 장비의 교체·갱신·재추첨 방식
