# Task K-05 - 눈삽

## 설명

녹슨·황금 눈삽의 밀치기, 눈 장전, 범위 공격과 내구도를 서버 권한으로 구현한다.

## 상태 전이 기준
- 시작 가능: K-01, C-07, C-09 완료
- 완료 가능: 공격·내구도·드롭 결과와 S-08·S-09 인계 확인

## 구현 항목
- [ ] 기본 공격이 근거리 대상을 밀친다.
- [ ] 눈 장전 중 이동속도를 낮추고 완료 뒤 전방 범위 공격을 실행한다.
- [ ] 눈 흩뿌리기 기본 피해 20을 서버가 적용한다.
- [ ] 녹슨 눈삽은 2~4 무작위 내구도, 황금 눈삽은 내구도 5회를 사용한다.
- [ ] 피격 시 자동 드롭하지 않고 `G`로 내려놓는다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: K 장비, C 피해·입력 계약
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-07, C-09, S-08, S-09
- 병합 순서: 선행 계약 후, K-09·K-10 전

## 공용 계약과 인계
- 제공받을 계약: C-07 피해·보정, C-09 조준·피격 결과
- 제공할 계약: 장전·공격·내구도·보유 상태
- 인계 대상: S-08, S-09
