# Task K-03 - 회복·무적 소비 아이템

## 설명

핫초코, 붕어빵, 에너지 드링크와 황금 붕어빵의 소비 효과를 서버 권한으로 적용한다.

## 상태 전이 기준
- 시작 가능: K-01 완료
- 완료 가능: 회복·무적·지속 회복 결과와 S-09 인계 확인

## 구현 항목
- [ ] 핫초코와 붕어빵이 HP 35를 회복한다.
- [ ] 에너지 드링크가 5초 동안 무적을 적용한다.
- [ ] 황금 붕어빵이 30초간 초당 HP 2를 회복한다.
- [ ] 최대 HP, 얼음·사망과 중복 효과 조건을 서버가 검사한다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: K 아이템, C 플레이어 효과 계약
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-07, S-08, S-09
- 병합 순서: K-01 후, K-09·K-10 전

## 공용 계약과 인계
- 제공받을 계약: C-07 회복·무적 계약
- 제공할 계약: 소비 결과와 남은 지속시간
- 인계 대상: S-09
