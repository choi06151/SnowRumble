# Task K-07 - 핫팩

## 설명

일반 핫팩의 소유·표시·완료 시 소모와 황금 핫팩의 팀 부활 요청을 C의 부활 계약에 연결한다.

## 상태 전이 기준
- 시작 가능: K-01, C-06, C-07, C-13 완료
- 완료 가능: 취소·완료·소모와 S-07·S-08·S-09 인계 확인

## 구현 항목
- [ ] 일반 핫팩 보유 상태를 서버가 관리하고 뒷주머니 외형·아군 UI에 제공한다.
- [ ] 부활이 취소되면 소모하지 않고 완료될 때 한 개를 소모한다.
- [ ] 황금 핫팩이 허용된 팀원을 즉시 부활시키는 요청을 실행한다.
- [ ] 적에게 UI 보유 상태를 노출하지 않는다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: K 아이템, C 부활 계약
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-06, C-07, S-07, S-08, S-09
- 병합 순서: C 부활 계약 후, K-09·K-10 전

## 공용 계약과 인계
- 제공받을 계약: C-06 얼음·사망, C-13 부활
- 제공할 계약: 핫팩 보유·소모·팀 부활 결과
- 인계 대상: S-07, S-08, S-09

## 범위 밖
