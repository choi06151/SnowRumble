# Task K-02 - 선물상자

## 설명

서버가 유효한 Spawn Point에 선물상자를 생성하고 근처에서 `E`를 먼저 완료한 플레이어에게 아이템 하나를 지급한다.

## 상태 전이 기준
- 시작 가능: K-01, C-05 완료
- 완료 가능: 일반·마지막 금색 상자와 S-09·맵 담당 인계 확인

## 구현 항목
- [ ] 시작 지점·플레이어 바로 아래를 피하는 서버 Spawn Point 선택을 제공한다.
- [ ] 시작 30초 첫 상자와 5분 30초 중앙 금색 상자를 생성한다.
- [ ] 근접 `E` 상호작용을 서버가 검증하고 최초 유효 플레이어를 획득자로 확정한다.
- [ ] 상자 하나에서 아이템 하나만 지급하고 중복 획득을 막는다.
- [ ] 파랑·빨강·금색 등급과 후보 풀을 구분한다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: 강혜원(K), 경기 시점은 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-05, S-09, S-10, J-02, J-04
- 병합 순서: K-01·C-05 후, 맵 배치·S-09 전

## 공용 계약과 인계
- 제공받을 계약: C-05 라운드 시점, K-01 아이템 지급
- 제공할 계약: Spawn Point 조건, 상자 상태·등급·보상 이벤트
- 인계 대상: S-09, S-10, J-02, J-04

## 범위 밖
- 상자 공격 개봉과 상자 모델 제작

## 사전 전제
- K-01
- C-05

## 결정 필요
- 일반 상자 생성 주기·최대 수량·등급 확률
- 붕어빵의 일반 상자 등급
