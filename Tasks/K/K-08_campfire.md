# Task K-08 - 모닥불

## 설명

기본 배치와 모닥불 키트가 동일한 Blueprint와 서버 규칙을 사용해 양 팀을 회복하고 눈덩이 피격으로 꺼지게 한다.

## 상태 전이 기준
- 시작 가능: K-01, C-07, C-09 완료
- 완료 가능: 회복·피격·꺼짐과 맵·S-08 인계 확인

## 구현 항목
- [ ] 기본 모닥불과 키트 모닥불이 동일한 게임플레이 Blueprint를 사용한다.
- [ ] 범위 안 모든 플레이어를 팀과 관계없이 초당 HP 4 회복한다.
- [ ] 작은 눈 5회 또는 큰 눈 2회 적중하면 서버가 꺼짐을 확정한다.
- [ ] 불꽃 축소와 연기 증가를 위한 상태를 표현 파트에 제공한다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: K 모닥불, C 회복·눈 피격 계약
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: S-08, S-10, J-02, J-04
- 병합 순서: 선행 계약 후, 맵 배치와 K-10 전

## 공용 계약과 인계
- 제공받을 계약: C-07 회복, C-09 눈 피격
- 제공할 계약: 배치 가능 모닥불, 활성·꺼짐·표현 상태
- 인계 대상: S-08, S-10, J-02, J-04

## 범위 밖
