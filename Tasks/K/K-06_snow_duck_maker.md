# Task K-06 - 눈오리 제작기

## 설명

일반·황금 눈오리 제작기가 눈 공격 피해량을 각각 10%·25% 증가시키는 장비 상태를 제공한다.

## 상태 전이 기준
- 시작 가능: K-01, C-07, C-09 완료
- 완료 가능: 피해 보정과 S-08·S-09 인계 확인

## 구현 항목
- [ ] 일반 눈오리 제작기가 눈 공격 피해를 10% 증가시킨다.
- [ ] 황금 눈오리 제작기가 눈 공격 피해를 25% 증가시킨다.
- [ ] 서버가 장비 소유와 피해 보정 적용 대상을 검증한다.
- [ ] 외형·UI가 읽을 등급과 장착 상태를 제공한다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: K 장비, C 눈 피해 계약
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-09, S-08, S-09
- 병합 순서: 선행 계약 후, K-09·K-10 전

## 공용 계약과 인계
- 제공받을 계약: C-07·C-09 피해 보정
- 제공할 계약: 장착 등급과 보정 상태
- 인계 대상: S-08, S-09
