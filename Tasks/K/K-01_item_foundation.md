# Task K-01 - 아이템 기반

## 설명

아이템 생성·획득·소유·사용·소모 상태를 서버가 관리하고 개별 아이템이 공용 효과 계약을 통해 동작할 기반을 만든다.

## 상태 전이 기준
- 시작 가능: C-01, C-07 완료
- 완료 가능: 아이템 공통 상태와 S-08·S-09 인계 확인

## 구현 항목
- [ ] 서버가 아이템 생성, 획득자, 소유와 소모 결과를 확정한다.
- [ ] 사용형과 착용·장비형의 공통 수명주기를 구분한다.
- [ ] 인벤토리 없이 즉시 사용 또는 외형·장비 상태로 반영한다.
- [ ] 개별 아이템이 C-07 효과 계약을 사용하게 한다.

## 작업 배정
- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: K 내부 계약은 강혜원(K), 플레이어·경기 계약은 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C, S
- 병합 순서: C-07 후, K-02~K-10 전

## 공용 계약과 인계
- 제공받을 계약: C-07 효과 요청과 상태 조회
- 제공할 계약: 아이템 상태·소유·사용·소모 이벤트
- 인계 대상: S-08, S-09, K 후속 Task

## 범위 밖
- 개별 아이템 효과와 모델·UI 제작

## 사전 전제
- C-01
- C-07

## 결정 필요
- 중복 획득과 기존 장비 교체 시 처리

## 완료 조건

- [ ] 플레이어 내부 상태 직접 변경 없음
- [ ] 후속 계약 인계 완료
