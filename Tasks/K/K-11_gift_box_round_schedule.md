# Task K-11 - 선물상자 라운드 스케줄 연결

## 설명

C-05의 라운드 시간·단계 계약에 맞춰 시작 30초 첫 상자와 5분 30초 마지막 금색 상자를 K-02 선물상자 기능에 연결한다.

## 상태 전이 기준

- 시작 가능: K-02, C-05, K-09 완료
- 완료 가능: 첫 상자·마지막 금색 상자 생성 시점과 보상 결과 확인

## 구현 항목

- [ ] 라운드 시작 30초 후 첫 번째 상자를 맵 중앙과 가까운 유효 지점에 생성한다.
- [ ] 5분 30초에 마지막 금색 상자를 맵 중앙에 생성한다.
- [ ] 라운드가 종료되거나 맵이 전환될 때 남은 상자 상태를 정리한다.
- [ ] 금색 보상 후보와 지급 결과를 K-09 계약으로 연결한다.

## 작업 배정

- 담당자·기능·자산 수정자: 강혜원(K)
- 계약 소유자: K 선물상자, 경기 시점은 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-05, S-09, S-10, J-02, J-04
- 병합 순서: K-02·C-05·K-09 후, K-10 전

## 공용 계약과 인계

- 제공받을 계약: K-02 선물상자 생성·보상, C-05 라운드 시점, K-09 금색 보상
- 제공할 계약: 첫 상자·마지막 금색 상자 생성 결과
- 인계 대상: K-10, S-09, C-12

## 범위 밖

- 선물상자 기본 상호작용
- 신규 황금 아이템 추가
- 맵별 Spawn Point 배치
