# Task S-05 - 머리 위 팀 이름표

## 설명

플레이어 머리 위에 닉네임과 팀 색이 같은 테두리를 표시해 목도리 없이도 팀을 구분하게 한다.

## 상태 전이 기준
- 시작 가능: C-08 완료
- 완료 가능: 거리·시야와 호스트·클라이언트별 팀 색 표시 확인

## 구현 항목
- [ ] 캐릭터 머리 위에 닉네임 UI를 표시한다.
- [ ] 이름표 테두리 색을 해당 플레이어의 팀 색과 일치시킨다.
- [ ] 플레이어 수와 거리 변화에서도 읽을 수 있게 구성한다.
- [ ] 얼음·사망·관전 상태에서 필요한 표시 변화를 제공한다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: UI는 S, 닉네임·팀 상태는 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-08, C-06
- 병합 순서: C-08 후

## 공용 계약과 인계
- 제공받을 계약: C-08 닉네임·팀 색, C-06 생존 상태
- 제공할 계약: 이름표 자산과 표시 조건
- 인계 대상: C-12

## 범위 밖
- 팀 배정과 닉네임 검증

## 사전 전제
- C-08

## 결정 필요
