# Task S-03 - 대기방 팀·준비 UI

## 설명

서버가 무작위 배정한 두 팀의 참가자, 팀 색, 준비 상태와 호스트 시작 가능 여부를 대기방에 표시한다.

## 상태 전이 기준
- 시작 가능: C-03 완료
- 완료 가능: 1vs1~4vs4 팀 목록과 준비·시작 UI 결과 확인

## 구현 항목
- [ ] 두 팀의 플레이어 목록, 닉네임, 팀 색과 준비 상태를 표시한다.
- [ ] 팀 인원이 다르면 시작할 수 없는 이유를 표시한다.
- [ ] 준비·준비 해제와 호스트 전용 시작 요청 UI를 제공한다.
- [ ] MVP에서 직접 팀 선택 UI를 제공하지 않는다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: UI는 S, 팀·준비·시작 상태는 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-03
- 병합 순서: C-03 후

## 공용 계약과 인계
- 제공받을 계약: C-03 팀·준비·시작 가능 상태와 요청
- 제공할 계약: 대기방 UI 자산과 누락 상태 요청
- 인계 대상: C-12

## 범위 밖
