# Task S-06 - 게임플레이 HUD

## 설명

기존 체력·조준·충전·행동 진행 UI를 통합하고 상호작용 안내, 마지막 생존자와 이모션 메뉴를 완성한다.

## 상태 전이 기준
- 시작 가능: C-07, C-09, C-10 완료
- 완료 가능: 로컬 플레이어 HUD와 머리 위 진행도 결과 확인

## 구현 항목
- [ ] 내 체력과 다른 플레이어 체력 표시를 실제 상태에 연결한다.
- [ ] 조준점, 작은·큰 눈 충전과 눈 제작·굴리기 진행도를 표시한다.
- [ ] 눈 제작, 줍기·굴리기와 필요한 상황별 안내 문구를 표시한다.
- [ ] 마지막 생존자 안내와 기존 이모션 원형 메뉴를 통합한다.
- [ ] 로컬 플레이어에게 필요한 정보만 표시한다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: UI는 S, 게임 상태는 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-07, C-09, C-10
- 병합 순서: C 계약 후

## 공용 계약과 인계
- 제공받을 계약: C-07 효과 상태, C-09 눈 상태, C-10 이모션 요청
- 제공할 계약: HUD·진행도·이모션 UI 자산
- 인계 대상: C-12

## 범위 밖
- 서버 피해·행동·이모션 판정

## 사전 전제
- C-07
- C-09
- C-10

## 결정 필요
- HUD의 최종 레이아웃과 동시 안내 우선순위
