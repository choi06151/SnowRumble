# Task S-07 - 얼음·관전·부활 UI

## 설명

얼음 상태 60초, 사망·관전, 핫팩 보유와 10초 부활 진행·취소·3초 무적을 각 플레이어에게 필요한 범위로 표시한다.

## 상태 전이 기준
- 시작 가능: C-06, C-07, K-07 완료
- 완료 가능: 얼음·사망·부활 각 상태의 호스트·클라이언트 UI 확인

## 구현 항목
- [ ] 얼음 상태와 남은 60초를 표시한다.
- [ ] 관전 대상과 사망 상태를 구분해 표시한다.
- [ ] 아군 핫팩 보유 아이콘을 표시하고 적에게는 숨긴다.
- [ ] 부활 10초 진행·취소와 완료 뒤 3초 무적을 표시한다.
- [ ] 핫팩이 없을 때 안내 문구를 표시한다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: UI는 S, 상태는 C·K
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-06, C-07, K-07
- 병합 순서: C·K 계약 후

## 공용 계약과 인계
- 제공받을 계약: C-06 생존·관전, C-07 부활·무적, K-07 핫팩 상태
- 제공할 계약: 얼음·관전·부활 UI 자산
- 인계 대상: C-12

## 범위 밖
