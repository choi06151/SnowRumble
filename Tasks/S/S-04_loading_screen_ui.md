# Task S-04 - 로딩 화면

## 설명

랜덤 선택된 맵 정보, 목표, 팁, 로딩 진행과 완료 인원을 표시하는 대기형 로딩 화면을 만든다.

## 상태 전이 기준
- 시작 가능: C-04 완료, 맵별 이미지 준비 가능
- 완료 가능: 전원 완료·30초 제한·연결 해제 상태 표시 확인

## 구현 항목
- [ ] 맵 이름, 이미지, 목표와 조작 팁을 표시한다.
- [ ] 현재 로딩 완료 인원과 진행 상태를 표시한다.
- [ ] 전원 완료 또는 제한시간 경과 상태를 구분한다.
- [ ] 로딩 실패로 연결 해제될 때 이해 가능한 안내를 제공한다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: UI는 S, 로딩 상태는 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-04, J, S-10
- 병합 순서: C-04와 맵 이미지 준비 후

## 공용 계약과 인계
- 제공받을 계약: C-04 선택 맵·로딩 인원·상태
- 제공할 계약: 로딩 UI와 맵 이미지 요구 규격
- 인계 대상: J-05, S-10, C-12
