# Task S-11 - 결과 UI

## 설명

## 상태 전이 기준
- 시작 가능: C-05 완료
- 완료 가능: 라운드 중간과 최종 매치 결과 UI 확인

## 구현 항목
- [ ] 라운드 승리 팀과 3초 결과 연출을 표시한다.

- [ ] 대기방으로 돌아가기와 방 나가기 요청 UI를 제공한다.
