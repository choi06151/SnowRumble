# Task S-02 - 메인 로비와 방 UI

## 설명

캐릭터가 보이는 메인 로비에서 빠른 게임, 방 만들기·참가, 옵션, 종료와 꾸미기 흐름을 제공한다.

## 상태 전이 기준
- 시작 가능: 레이아웃은 즉시, 데이터 연결은 C-02·C-11 완료 후
- 완료 가능: 각 요청·상태·오류 UI와 호스트·클라이언트 결과 확인

## 구현 항목
- [ ] 중앙 캐릭터와 로비 배경을 포함한 메인 화면을 구성한다.
- [ ] 빠른 게임, 방 만들기, 방 참가, 옵션, 종료, 꾸미기 진입을 제공한다.
- [ ] 방 이름·최대 인원·비밀번호 입력과 검색 결과를 표시한다.
- [ ] 마지막 커스터마이징 외형을 메인 캐릭터에 표시한다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: UI는 S, 세션·외형 데이터는 최재원(C)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-02, C-11
- 병합 순서: C 계약 후 UI 데이터 연결

## 공용 계약과 인계
- 제공받을 계약: C-02 방·세션 상태, C-11 외형 상태
- 제공할 계약: UI 자산 이름과 필요한 누락 데이터
- 인계 대상: C-12

## 범위 밖
- 세션·비밀번호 검증과 커스터마이징 저장 로직

## 사전 전제
- C-02
- C-11
