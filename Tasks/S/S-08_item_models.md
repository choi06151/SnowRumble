# Task S-08 - 아이템 모델과 장비 외형

## 설명

일반·황금 아이템, 선물상자와 모닥불 모델을 제작하고 부츠·패딩·장갑·핫팩이 캐릭터 외형에 읽히게 연결한다.

## 상태 전이 기준
- 시작 가능: GDD 외형 목록 확정, 연결은 K 관련 Task 후
- 완료 가능: 모든 MVP 아이템의 모델·머티리얼·장비 연결 인계 완료

## 구현 항목
- [ ] 파랑·빨강·금색 선물상자 외형을 구분한다.
- [ ] 회복·무적·장비·전투·황금 아이템 모델을 제작한다.
- [ ] 부츠·패딩·장갑·핫팩이 장착 위치에서 식별되게 한다.
- [ ] 기본·키트 모닥불이 동일 게임플레이 Blueprint에서 사용할 표현 자산을 제공한다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: 모델은 S, 아이템 상태는 강혜원(K)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: K-02~K-09, S-01
- 병합 순서: 원본 모델 → K Blueprint 연결

## 공용 계약과 인계
- 제공받을 계약: K의 아이템 상태·등급·장착 지점 요구
- 제공할 계약: 모델·머티리얼·장착 자산 이름과 연결 조건
- 인계 대상: K-02~K-10

## 범위 밖
- 아이템 서버 로직과 능력 수치 판정

## 사전 전제
- S-01 캐릭터 장비 영역

## 결정 필요
- 붕어빵과 핫초코의 시각적 차이, 황금 아이템 공통 표현 규칙
