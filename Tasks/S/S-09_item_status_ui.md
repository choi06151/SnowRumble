# Task S-09 - 아이템 상태와 보상 UI

## 설명

아이템 획득, 장비 상태, 지속시간, 내구도, 상자 등장과 금색 보상을 로컬 플레이어에게 필요한 범위로 표시한다.

## 상태 전이 기준
- 시작 가능: K-01~K-09의 관련 계약 완료
- 완료 가능: 모든 MVP 아이템의 표시와 정보 비노출 결과 확인

## 구현 항목
- [ ] 상자 등장과 획득 아이템 안내를 표시한다.
- [ ] 착용 장비, 능력 보정과 전투 장비 내구도를 표시한다.
- [ ] 무적·지속 회복 등 시간 제한 효과를 표시한다.
- [ ] 마지막 금색 상자와 획득 보상을 강조한다.
- [ ] 적에게 공개하지 않을 아이템 상태를 숨긴다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: UI는 S, 아이템 상태는 강혜원(K)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: K-01~K-09
- 병합 순서: K 개별 계약 후, K-10 전

## 공용 계약과 인계
- 제공받을 계약: K 아이템 상태·지속시간·내구도·보상 이벤트
- 제공할 계약: 아이템 UI·아이콘과 누락 데이터 요청
- 인계 대상: K-10, C-12

## 범위 밖
- 아이템 효과와 보상 결정

## 사전 전제
- K-01~K-09 중 표시 대상 계약

## 결정 필요
- HUD에 동시에 표시할 장비·효과의 최대 개수
