# Task S-10 - 눈숲속 맵

## 설명

눈숲속의 전투 동선과 팀·아이템 배치를 만들고 이동 영역을 좁히는 `눈 폭` 환경 압박 로직과 폭설 VFX를 구성한다.

## 상태 전이 기준
- 시작 가능: 블록아웃은 즉시, 게임플레이 연결은 C-04·C-05·C-07·C-14·K-02·K-08 완료 후
- 완료 가능: 맵 단독 소유, 눈 폭 서버 로직·공용 계약 연결과 호스트·클라이언트 결과 확인

## 구현 항목
- [ ] 1vs1~4vs4 전투가 가능한 눈숲속 지형과 동선을 구성한다.
- [ ] 팀 시작 지점, 기본 눈덩이, 선물상자 Spawn Point와 기본 모닥불 후보를 배치한다.
- [ ] 눈 폭의 안전·위험 경계와 접근 방향을 폭설 VFX로 표현한다.
- [ ] 6분 이후 전투 공간이 줄어드는 눈 폭 환경 압박 로직을 맵 전용 Actor·Component·Blueprint로 구현한다.
- [ ] 주요 규칙을 Level Blueprint에 중복 구현하지 않는다.

## 작업 배정
- 담당자·기능·자산 수정자: 서유정(S)
- 계약 소유자: 맵·VFX·눈 폭 환경 로직은 S, 공용 피해·경기 계약은 최재원(C), 아이템 배치는 강혜원(K)
- 생성·변경 후보: 구현 승인 전 확정
- 공유 확인 대상: C-04, C-05, C-07, C-14, K-02, K-08
- 병합 순서: 블록아웃 → 공용 Actor·계약 → 아이템 배치 → 통합

## 공용 계약과 인계
- 제공받을 계약: C 랜덤 맵·경기 시간·피해·스폰, K 상자·모닥불 배치 대상
- 제공할 계약: 맵 자산, Spawn Point·기본 눈덩이·환경 압박 로직·로딩 이미지
- 인계 대상: C-04, C-12, S-04, K-10

## 범위 밖
- 공용 플레이어·경기 상태 직접 변경

## 사전 전제

## 결정 필요
