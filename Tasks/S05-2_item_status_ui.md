# SUB UI Task S05-2 - 보상과 아이템 상태 UI

## 설명

선물상자 보상과 로컬 플레이어가 보유·사용·장착한 MVP 아이템 상태를 간단히 확인할 수 있는 UI를 구성한다.

## 구현 항목

- [ ] 선물상자에서 획득한 보상 결과를 표시한다.
- [ ] 현재 확인이 필요한 MVP 아이템 보유·사용·장착 상태를 표시한다.
- [ ] 상태가 변경되면 현재 서버 결과에 맞게 UI를 갱신한다.
- [ ] 표시할 아이템이 없을 때 불필요한 UI를 숨긴다.
- [ ] UI가 보상 결정, 아이템 획득·사용·장착 효과를 직접 적용하지 않는다.

## 범위 밖

- 일반 인벤토리와 모든 장기 아이템 UI
- 보상 추첨과 아이템 게임플레이 효과
- 아이템 모델·장착 위치와 사용 연출

## 사전 전제

- Main Task 05-2의 보상 결과 이벤트
- Main Task 05-3에서 확정한 MVP 아이템 목록과 로컬 표시 상태

## 작업 배정

- 담당자: SUB 프로그래머
- 선점 UI 자산: Main Task 인계 후 확정
- 공유 확인 대상: 보상과 아이템 상태 변경 표시
- 반영 순서: Main Task 05-2와 05-3 완료 후 시작
