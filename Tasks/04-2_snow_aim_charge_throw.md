# Task 04-2 - 눈 조준, 충전, 투척

## 설명

작은 눈덩이를 든 플레이어가 조준하고 투척 힘을 충전한 뒤 화면 중앙 방향으로 던질 수 있게 한다.

## 구현 항목

- [ ] 작은 눈덩이를 든 상태에서 조준할 수 있다.
- [ ] 조준 중 투척 입력을 유지하면 힘이 충전된다.
- [ ] 입력을 놓으면 충전량에 따른 힘으로 눈덩이가 날아간다.
- [ ] 눈덩이가 화면 중앙을 기준으로 의도한 방향에 날아간다.
- [ ] 투척된 눈덩이의 이동과 충돌이 모든 참가자에게 일관되게 보인다.

## 메인 프로그래머 책임

- 조준 입력·카메라, 충전 요청·검사, 투척 확정·복제와 비UI 애니메이션·사운드·이펙트를 완성한다.

## SUB UI 인계

- 연계 SUB Task: `Tasks/S04-2_aim_charge_ui.md`
- 로컬 조준 여부, 정규화된 충전 진행도와 눈덩이 크기 구분을 UI가 읽거나 변경 알림을 받을 수 있게 제공한다.
