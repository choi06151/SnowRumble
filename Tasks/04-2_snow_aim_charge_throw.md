# Task 04-2 - 눈 조준, 충전, 투척

## 설명

작은 눈덩이를 든 플레이어가 조준하고 투척 힘을 충전한 뒤 화면 중앙 방향으로 던질 수 있게 한다.

## 구현 항목

- [x] 작은 눈덩이를 든 상태에서 조준할 수 있다.
- [x] 조준 중 투척 입력을 유지하면 힘이 충전된다.
- [x] 입력을 놓으면 충전량에 따른 힘으로 눈덩이가 날아간다.
- [x] 눈덩이가 화면 중앙을 기준으로 의도한 방향에 날아간다.
- [x] 투척된 눈덩이의 이동과 충돌이 모든 참가자에게 일관되게 보인다.

## 메인 프로그래머 책임

- 조준 입력·카메라, 충전 요청·검사, 투척 확정·복제와 비UI 애니메이션·사운드·이펙트를 완성한다.

## SUB UI 인계

- 연계 SUB Task: `Tasks/S04-2_aim_charge_ui.md`
- 로컬 조준 여부, 정규화된 충전 진행도와 눈덩이 크기 구분을 UI가 읽거나 변경 알림을 받을 수 있게 제공한다.

## 범위 밖

- 플레이어 HP 감소
- 큰 눈덩이의 광역 공격
- 최종 조준·투척 애니메이션과 완성형 충돌 이펙트 자산

## 사전 전제

- Task 04-1의 바닥 눈덩이 획득·장착 단위

## 현재 구현 단위

- 첫 번째 단위로 눈덩이를 보유한 상태의 우클릭 조준, 로컬 FOV 확대, 조준 이동 감속, 스프린트 차단과 조준 상태 복제를 구현했다.
- 두 번째 단위로 조준 중 좌클릭 충전, 임시 문자열 충전율 표시와 충전량 비례 투척을 구현했다.
- 실제 투척은 반드시 서버가 `눈덩이 보유 + 조준 중`을 확인한 경우에만 허용한다.
- 서버가 최대 `2초`의 충전시간을 측정해 투척 속도를 `900~2400` 사이로 확정한다.
- 장착된 `ASnowballItem` 자체를 `Held → Thrown` 상태로 전환하며 별도 프로토타입 Projectile을 생성하지 않는다.
- 투척된 `ASnowballItem`은 서버의 Blocking Hit 또는 투사체 정지 이벤트에서 충돌을 확정하고, 모든 참가자에게 `Play Impact Effect` Blueprint 이벤트를 전달한 뒤 제거한다.
- 벽처럼 충돌 Actor가 없는 Blocking Hit도 눈덩이 제거와 이펙트 재생 대상으로 처리한다.
- 로컬 카메라는 평소에도 마우스를 왼쪽으로 돌리면 오른쪽 어깨, 오른쪽으로 돌리면 왼쪽 어깨로 이동하며 기본 `75cm` 오프셋을 사용한다.
- 조준 중에는 마우스를 왼쪽으로 돌리면 오른쪽 어깨, 오른쪽으로 돌리면 왼쪽 어깨로 이동하며 오프셋이 기본 `90cm`로 넓어지고 Spring Arm 길이가 `340cm`로 가까워진다.
- 평소와 조준 중 모두 회전 입력을 멈추면 마지막 어깨 위치를 유지한다.
- 조준을 해제하면 현재 어깨 방향을 유지한 채 기본 오프셋과 기존 Spring Arm 길이로 부드럽게 돌아온다.
- 조준 시작·해제 시 FOV는 `Aim Field Of View Interp Speed`를 사용해 기본 FOV와 조준 FOV 사이를 부드럽게 보간한다.
- 투척 입력을 놓으면 게임플레이 조준은 즉시 종료하지만 로컬 카메라는 기본 `1초` 동안 조준 거리·어깨 오프셋·FOV를 유지해 날아가는 눈덩이를 보여준 뒤 기본 시점으로 돌아온다.
- Spring Arm의 회전 중심은 기본 `65cm` 높이로 올리고 Probe Size `12cm`의 카메라 충돌을 유지해 위를 볼 때 바닥 충돌로 캐릭터에게 붙는 현상을 줄인다.
- 로컬 카메라의 상하 시야각은 기본 `-65~55도`로 제한해 Spring Arm이 지면이나 캐릭터에 과도하게 가까워지는 각도를 막는다.

## 수동 작업

1. Unreal Editor를 종료한 상태에서 프로젝트를 다시 빌드하고 연다.
2. `BP_SnowRumbleCharacter`에서 필요하면 `Aim Walk Speed`와 `Aim Field Of View` 기본값을 조정한다. C++ 기본값은 각각 `300`, `75`다.
3. `BP_SnowRumbleCharacter`의 Animation Blueprint에서는 캐릭터의 순수 함수 `Is Aiming`을 조준 자세 전환 조건으로 사용한다.
4. `BP_SnowballItem`에서 `Event Play Impact Effect`를 구현하고 전달되는 `Impact Point`와 `Impact Normal`을 사용해 충돌 Niagara·파티클 또는 사운드를 재생한다.
5. `BP_SnowRumbleCharacter`에서 필요하면 `Default Shoulder Offset` 기본 `75`, `Aim Shoulder Offset` 기본 `90`, `Aim Camera Arm Length` 기본 `340`, `Camera Position Interp Speed` 기본 `1`, `Aim Field Of View Interp Speed` 기본 `3`, `Post Throw Camera Hold Seconds` 기본 `1`을 조정한다.
6. 필요하면 `Camera Pivot Height` 기본 `65`, `Camera View Pitch Min` 기본 `-65`, `Camera View Pitch Max` 기본 `55`와 Camera Boom의 `Probe Size` 기본 `12`를 조정한다.
7. Listen Server 2인 PIE를 실행하고 호스트와 클라이언트가 각각 바닥 눈덩이를 획득한다.
8. 각 플레이어가 우클릭을 누르고 있는 동안 조준 상태·FOV·이동속도를 확인하고, Shift를 함께 눌러 속도가 증가하지 않는지 확인한다.
9. 눈덩이가 없는 상태, 얼어 있는 상태에서는 조준이 시작되지 않는지 확인한다.
10. 우클릭 해제 시 FOV와 이동속도가 원래 값으로 돌아오는지 확인한다.
11. 조준 중 좌클릭을 누르면 소유 플레이어 화면의 `Snowball Charge: 0~100%` 문자열이 증가하는지 확인한다.
12. 짧게 충전했을 때보다 약 `2초` 충전했을 때 눈덩이가 더 빠르고 멀리 날아가는지 확인한다.
13. 좌클릭 해제 후 손의 눈덩이가 사라지고 동일한 눈덩이가 화면 중앙 방향으로 날아가는지 확인한다.
14. 조준하지 않은 상태의 좌클릭으로는 충전하거나 던질 수 없는지 확인한다.
15. 호스트가 클라이언트를, 클라이언트가 호스트를 맞혔을 때 기존 피해·충돌 동작이 유지되는지 확인한다.
