# Task 05-4 - 게임플레이 UI 데이터 연결

## 설명

SUB 프로그래머가 MVP HUD를 만들 수 있도록 현재 HP, 행동 진행도, 들고 있는 대상과 상호작용 상태를 로컬 플레이어 기준의 데이터와 이벤트로 제공한다.

## 구현 항목

- [ ] 자신의 현재 HP를 UI가 읽거나 변경 알림을 받을 수 있다.
- [ ] 눈 제작과 투척 충전 진행도를 UI가 받을 수 있다.
- [ ] 가까운 상호작용 대상과 가능한 행동을 UI가 받을 수 있다.
- [ ] 현재 들고 있거나 착용한 MVP 대상의 상태를 UI가 받을 수 있다.
- [ ] 얼기와 관전 상태를 UI가 구분할 수 있는 데이터를 제공한다.
- [ ] 각 데이터가 로컬 플레이어 소유 상태를 기준으로 제공된다.

## 메인 프로그래머 책임

- UI용 데이터의 소유자, 초기값 조회와 갱신 이벤트를 C++ 또는 메인 소유 게임플레이 Blueprint에서 제공한다.

## SUB UI 인계

- 연계 SUB Task: `Tasks/S05-3_gameplay_hud.md`
- 실제 연결 지점의 이름, 값의 의미, 호출 위치와 로컬 플레이어 접근 방법을 기록한다.
