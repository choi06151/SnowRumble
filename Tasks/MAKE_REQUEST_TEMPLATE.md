# 사용자 요청

- 개발자가 아래 요청만 전달하면 Codex가 현재 담당자의 `PLAN_*.md`와 Task 문서를 작성·갱신해줘.
- 현재 담당자, 역할 문서, 역할 계획과 `docs/PLANS.md`의 공용 의존성·소유권을 먼저 확인해줘.
- 범위가 너무 크거나 다른 담당자의 소유권과 충돌하면 Task를 만들지 말고 분리안과 인계 대상을 먼저 알려줘.
- 역할 내부 변경이면 Codex가 우선순위·상태·Task 추가를 반영하고, 파트 간 영향이 있으면 `통합 변경 요청`에 기록해줘.
