# Task 06-2 - 결과 화면과 MVP 통합 검증

## 설명

경기 종료 결과와 다음 흐름을 UI에 제공하고, SnowRumble MVP의 전체 LAN 멀티플레이 루프를 통합 확인한다.

## 구현 항목

- [ ] 경기 종료 시 승리와 패배 결과를 구분된 상태로 제공한다.
- [ ] 결과 확인 후 합의된 다음 흐름으로 이동할 수 있다.
- [ ] MVP 핵심 행동에 필요한 최소 사운드 피드백을 제공한다.
- [ ] Host부터 경기 종료까지 전체 MVP 흐름이 이어진다.
- [ ] 권장 인원과 최대 지원 목표를 고려한 단계별 멀티플레이 검증 결과를 기록한다.
- [ ] MVP 범위에서 발견된 문제와 후속 조정 항목을 정리한다.

## 메인 프로그래머 책임

- 경기 종료 상태, 다음 흐름, MVP 사운드·비UI 표현과 전체 네트워크 루프의 코드·복제 문제를 완성한다.
