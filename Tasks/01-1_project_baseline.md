# Task 01-1 - 프로젝트 기반 확인

## 설명

SnowRumble의 Unreal Engine 5.8 프로젝트가 이후 기능 개발을 시작할 수 있는 기본 상태인지 확인하고 프로젝트 기준을 고정한다.

## 구현 항목

- [x] 프로젝트가 Unreal Engine 5.8에서 열릴 수 있는 기본 구성을 갖춘다.
- [x] 런타임 모듈과 프로젝트 기본 설정의 시작 상태를 확인한다.
- [x] 이후 사용할 기본 테스트 맵과 게임 시작 흐름을 준비한다.

## 메인 프로그래머 책임

- Unreal C++ 런타임 모듈, 기본 테스트 맵과 이후 기능이 사용할 코드·에디터 시작 상태를 준비한다.
- 이 단계에는 SUB UI 작업이 없다.

## 범위 밖

- 플레이어 조작
- LAN 세션
- 눈덩이와 전투 기능

## 수동 작업

1. Unreal Editor 5.8에서 `SnowRumble.uproject`를 연다.
2. Content Browser에서 프로젝트 `Content` 바로 아래에 `Maps` 폴더를 만든다.
3. 새 빈 레벨을 만든다.
4. 기본 테스트가 가능하도록 바닥, `Player Start`, 조명과 하늘 등 최소 환경을 배치한다.
5. 레벨을 `/Game/Maps/L_Prototype` 이름으로 저장한다.
6. 저장 후 에디터를 종료했다가 다시 열어 `L_Prototype`이 자동으로 열리는지 확인한다.

## 완료 조건

### 에이전트 확인

- [x] 관련 코드 수정 완료 — 새 C++ 구현 없이 기존 Runtime 모듈과 Target 구성을 유지함
- [x] 로컬 정적 점검 또는 프로젝트 구조 기준 확인 완료
- [x] Unreal C++/Blueprint/에셋 규칙 위반 없음
- [x] 현재 task 문서가 실제 구현 기준으로 갱신됨

### 결과 확인

- [x] Unreal Editor 5.8에서 프로젝트가 오류 없이 열리는지 확인한다.
- [x] 시작할 때 `/Game/Maps/L_Prototype` 맵이 자동으로 열리는지 확인한다.
- [x] `L_Prototype`에 바닥, `Player Start`와 최소 조명이 보이는지 확인한다.
- [x] PIE를 1명으로 실행했을 때 테스트 맵에서 게임이 시작되는지 확인한다.
