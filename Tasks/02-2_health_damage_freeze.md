# Task 02-2 - HP, 피해, 얼기

## 설명

최소 네트워크 눈덩이가 플레이어에게 피해를 주고 HP가 모두 소진되면 플레이어가 얼어 전투에서 제외되는 첫 전투 세로 단면을 만든다.

## 구현 항목

- [ ] 플레이어가 서버 기준의 HP를 가진다.
- [ ] 최소 네트워크 눈덩이의 유효한 충돌이 피해로 처리된다.
- [ ] HP가 모두 소진되면 얼기 상태로 전환된다.
- [ ] 얼어있는 동안 이동과 일반 행동을 할 수 없다.
- [ ] 얼어있는 플레이어가 눈 공격을 막는 오브젝트로 동작한다.
- [ ] HP와 얼기 상태가 모든 참가자에게 동일하게 보인다.

## 메인 프로그래머 책임

- 서버 권한의 피해·HP·얼기 상태, 행동 제한과 비UI 피격·얼기 표현을 완성한다.
