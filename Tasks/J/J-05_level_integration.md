# Task J-05 - 얼음 빙하·눈섬 통합

## 설명

얼음 빙하와 눈섬을 랜덤 라운드·아이템·팀 스폰 계약에 연결하고 두 맵의 플레이 동선과 자산 누락을 최종 확인한다.

## 상태 전이 기준
- 시작 가능: J-02, J-04, K-10과 관련 C 계약 완료
- 완료 가능: 두 맵의 호스트·클라이언트 결과와 C-12 인계 완료

## 구현 항목
- [ ] 두 맵이 랜덤 맵 풀과 로딩 화면에서 올바르게 식별된다.
- [ ] 팀 시작, 상자, 모닥불과 환경 위험 배치를 확인한다.
- [ ] 1vs1~4vs4에서 막힌 동선과 일방적 시작 위치가 없는지 확인한다.
- [ ] `.umap`과 맵 전용 자산의 소유권·참조 누락을 정리한다.

## 작업 배정
- 담당자·기능·자산 수정자: 정다영(J)
- 계약 소유자: 레벨은 J, 공용 계약은 C·K
- 생성·변경 후보: 통합 승인 전 확정
- 공유 확인 대상: C, K, S
- 병합 순서: C·K 계약 → J 두 맵 → C-12

## 공용 계약과 인계

- 제공할 계약: 최종 두 맵 자산·배치·검증 결과
- 인계 대상: C-12, S-04
