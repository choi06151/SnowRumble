# Task J-06 - 눈숲속 맵

## 설명

지난주 팀 회의에서 S에서 J로 담당이 변경된 눈숲속 맵 제작을 J 범위로 이어받아, 1vs1~4vs4 전투가 가능한 숲 지형·동선·배치 후보와 `눈 폭` 환경 압박을 얹을 공간 구조를 준비한다.

## 상태 전이 기준

- 시작 가능: 담당 변경 합의 확인. Blockout은 즉시 시작 가능, Gameplay 연결은 C-04·C-05·C-07·C-14·K-02·K-08 또는 대응 공용 계약 확인 후 진행
- 완료 가능: 눈숲속 맵 단독 소유, Blockout·배치 후보·눈 폭 경계 후보 정리, 필요한 공용 계약 인계와 호스트·클라이언트 결과 확인

## 구현 항목

- [ ] 기존 S-10 요구사항을 J Task로 이어받되, S의 기존 기록을 삭제하거나 J가 처음부터 진행한 것처럼 바꾸지 않는다.
- [ ] 1vs1~4vs4 전투가 가능한 눈숲속 지형과 주요 동선을 구성한다.
- [ ] 중앙 전투 공간, 외곽 숲길, 우회 동선과 시야 차단 구조를 Blockout으로 만든다.
- [ ] 팀 시작 지점, 기본 눈덩이, 선물상자 Spawn Point와 기본 모닥불 후보 공간을 마련한다.
- [ ] `눈 폭`이 좁혀오는 안전·위험 경계와 접근 방향을 공간 구조로 표시한다.
- [ ] 6분 이후 전투 공간이 줄어드는 눈 폭 환경 압박 로직을 얹을 수 있는 배치 여유를 확보한다.
- [ ] 주요 규칙을 Level Blueprint에 중복 구현하지 않는다.
