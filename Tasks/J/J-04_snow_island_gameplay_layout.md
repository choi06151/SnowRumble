# Task J-04 - 눈섬 게임플레이 배치

## 설명

눈섬에 팀 시작 지점, 상자·모닥불 후보와 자기장 환경 계약을 배치해 플레이 가능한 맵으로 완성한다.

## 상태 전이 기준
- 시작 가능: J-03, C-04, C-07, C-08, K-02, K-08 완료
- 완료 가능: 자기장·스폰·아이템 배치의 호스트·클라이언트 결과 확인

## 구현 항목
- [ ] 팀별 시작 지점과 5초 소개 공간을 배치한다.
- [ ] 선물상자 Spawn Point와 기본 모닥불 후보를 배치한다.
- [ ] 자기장 안전·위험 경계와 축소 방향을 시각적으로 전달한다.
- [ ] 6분 이후에도 중앙 전투가 지속될 최소 공간을 남긴다.
- [ ] 주요 판정을 Level Blueprint에 중복 구현하지 않는다.
