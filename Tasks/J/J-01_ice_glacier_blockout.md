# Task J-01 - 얼음 빙하 블록아웃

## 설명

1vs1~4vs4 전투와 단계별 수위 상승을 고려한 얼음 빙하 맵의 기본 지형·동선·고저차를 구성한다.

## 상태 전이 기준
- 시작 가능: 즉시
- 완료 가능: 블록아웃 동선과 침수 단계별 영역 검토 완료

## 구현 항목
- [ ] 양 팀이 공정하게 접근할 수 있는 기본 전투 공간을 만든다.
- [ ] 0~4분, 4~5분, 5~6분, 6분 이후 침수 영역을 공간으로 구분한다.
- [ ] 중앙 전투와 외곽 탈출 동선을 확보한다.
- [ ] 팀 시작·기본 눈덩이·상자·모닥불 후보 공간을 마련한다.
