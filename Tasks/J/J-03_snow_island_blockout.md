# Task J-03 - 눈섬 블록아웃

## 설명

자기장형 안전 영역 축소를 고려한 눈섬의 기본 지형, 전투 동선과 단계별 공간을 구성한다.

## 범위 해석

- `외곽 영역 → 중간 전투 영역 → 최종 교전 영역`은 자기장의 실제 3단계 규칙이 아니라 수치 없는 Level Design 공간 분류로만 사용한다.
- 고정·랜덤 중심, 실제 단계 수, 반경, 단계별 시간, 축소 속도와 피해는 이 Task에서 확정하거나 구현하지 않는다.
- 위 Gameplay 값은 향후 사용자·GDD 결정과 C의 공용 계약이 확정된 뒤 J-04에서 실제 공간 경계와 연결한다.
- J-03은 Level Editor와 `.umap` 블록아웃만 진행하며 Gameplay Blueprint와 C++를 구현하지 않는다.

## 상태 전이 기준
- 시작 가능: 즉시
- 완료 가능: 블록아웃 동선과 안전 영역 축소 공간 검토 완료

## 구현 항목
- [ ] 1vs1~4vs4에서 공정한 팀별 진입 동선을 만든다.
- [ ] 자기장 축소 단계에 따라 전투가 중앙으로 모이는 공간을 구성한다.
- [ ] 큰 눈덩이와 근접 장비를 함께 사용할 수 있는 폭과 엄폐를 제공한다.
- [ ] 팀 시작·기본 눈덩이·상자·모닥불 후보 공간을 마련한다.
