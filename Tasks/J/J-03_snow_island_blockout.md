# Task J-03 - 눈섬 블록아웃

## 설명

자기장형 안전 영역 축소를 고려한 눈섬의 기본 지형, 전투 동선과 단계별 공간을 구성한다.

## 상태 전이 기준
- 시작 가능: 즉시
- 완료 가능: 블록아웃 동선과 안전 영역 축소 공간 검토 완료

## 구현 항목
- [ ] 1vs1~4vs4에서 공정한 팀별 진입 동선을 만든다.
- [ ] 자기장 축소 단계에 따라 전투가 중앙으로 모이는 공간을 구성한다.
- [ ] 큰 눈덩이와 근접 장비를 함께 사용할 수 있는 폭과 엄폐를 제공한다.
- [ ] 팀 시작·상자·모닥불 후보 공간을 마련한다.
