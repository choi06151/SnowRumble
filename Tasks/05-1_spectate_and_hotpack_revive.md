# Task 05-1 - 아군 관전과 핫팩 부활

## 설명

얼어붙은 플레이어가 생존한 같은 팀 플레이어를 관전하고, 핫팩을 가진 아군이 얼음을 녹여 약 3분의 1 HP로 부활시킬 수 있게 한다.

## 구현 항목

- [ ] 얼어붙은 플레이어가 생존한 같은 팀 플레이어를 관전한다.
- [ ] 핫팩 보유 상태를 구분할 수 있다.
- [ ] 핫팩을 가진 플레이어가 얼어붙은 아군에게 부활 상호작용을 할 수 있다.
- [ ] 부활이 완료되면 핫팩이 소모된다.
- [ ] 부활한 플레이어가 최대 HP의 약 3분의 1로 행동을 재개한다.
- [ ] 관전과 부활 결과가 관련 참가자에게 올바르게 반영된다.

## 메인 프로그래머 책임

- 아군 관전 대상·카메라, 핫팩 보유·소모, 서버 권한 부활 검사·HP 복구와 비UI 해동 표현을 완성한다.

## SUB UI 인계

- 연계 SUB Task: `Tasks/S05-1_spectate_revive_ui.md`
- 로컬 관전 상태·대상, 핫팩 보유 여부와 부활 상호작용 진행도를 UI가 읽거나 변경 알림을 받을 수 있게 제공한다.
