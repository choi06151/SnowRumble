# SUB UI Task S05-1 - 관전과 부활 UI

## 설명

얼어붙은 로컬 플레이어의 관전 상태와 핫팩을 사용하는 플레이어의 부활 상호작용 진행도를 표시한다.

## 구현 항목

- [ ] 얼어붙은 동안 현재 관전 중인 아군 정보를 표시한다.
- [ ] 관전 종료 시 관련 UI를 숨긴다.
- [ ] 핫팩 보유 여부와 부활 가능 상태를 표시한다.
- [ ] 부활 상호작용 중 진행도를 표시한다.
- [ ] UI가 관전 대상, 핫팩 소비, 부활 성공과 HP를 직접 변경하지 않는다.

## 범위 밖

- 관전 카메라와 대상 선정
- 핫팩 보유·소모와 서버 부활 판정
- 해동 애니메이션·이펙트·사운드
