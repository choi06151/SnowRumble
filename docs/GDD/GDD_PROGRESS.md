# SnowRumble GDD 진행 상태

## 현재 상태

- 프로젝트 버전: Prototype `v0.0.1`
- 기획 기준: `docs/GDD/Game_GDD.md`
- 기획 개편 기준일: 2026-08-07
- 구현 기준선: `docs/PROGRESS_BASELINE_2026-08-07.md`
- 현재 단계: 수정 GDD, 4인 협업 규칙, 역할별 Task와 Codex 대화 기반 자율 계획, 공용 Task 실행 Skill 구성 완료
- 기존 완료·진행중 Task는 당시 검증 이력으로 보존하며 새 기획에 맞는 유지·수정·대체·폐기 여부를 후속 Task에서 결정한다.

## 확정된 기술 방향

- Unreal Engine 5.8
- Listen Server
- OnlineSubsystem NULL
- LAN Session
- PC 우선 개발
- 방 최대 8명, 팀당 최대 4명
- 8개 팀 색 중 2개 이상 선택되고 각 팀 색 인원이 1~4명일 때 시작
- 기본 게임 모드: 3판 2선승 팀 PvP
- 서버가 라운드별 맵을 무작위 선택

## 현재 MVP 목표

### 접속과 경기 준비

- 메인 로비와 캐릭터 표시
- 빠른 게임
- LAN 방 만들기, 검색과 참가
- 방 이름, 최대 인원, 방 코드 입력 참가
- 최대 8명 대기방
- 게시판 팀 색 선택과 팀 색 기준 시작 검사
- 준비 상태와 호스트 시작
- 서버 랜덤 맵 선택
- 맵 정보, 팁, 로딩 완료 인원을 포함한 로딩 화면
- 최대 30초 로딩 대기와 실패 연결 해제
- 팀 시작 지점과 시작 5초 연출

### 플레이어와 전투

- 기본 이동, 카메라, 스프린트와 입력
- 눈 만들기, 줍기, 내려놓기
- 조준, 충전과 작은 눈 투척
- 눈 굴리기, 큰 눈 운반과 광역 투척
- HP, 피해와 얼기
- 60초 얼음 부활 가능 시간과 이후 사망
- 아군 관전
- 핫팩 10초 부활, HP 50% 복귀와 3초 무적
- 팀 전원 얼기 라운드 승패
- 3판 2선승 매치 흐름

### 보상과 아이템

- `E` 상호작용 선물상자
- 첫 상자와 5분 30초 마지막 금색 상자
- 기획서에 명시된 일반·황금 아이템 전체
- 기본 모닥불 4개와 모닥불 키트
- 장비 외형 반영과 핫팩 보유 표시

### UI와 커스터마이징

- 기본 HUD와 상황별 안내 문구
- 로비, PvP, 추후 좀비맵에서 재사용할 전체/팀 텍스트 채팅
- 팀 색상과 일치하는 닉네임 UI 테두리
- 핫팩 보유, 얼음 잔여시간, 부활 진행과 무적 표시
- 라운드와 매치 결과 화면
- 대기방 복귀와 방 나가기
- 자유 드로잉 기반 캐릭터 커스터마이징

### MVP 맵

- 얼음 빙하: 얼음물 수위 상승
- 눈섬: 자기장형 안전 영역 축소
- 눈숲속: 폭설 VFX로 표현하는 `눈 폭` 영역 축소
- 각 라운드 서버 무작위 맵 선택과 연속 중복 최소화

## MVP 이후

- 게시판 직접 팀 선택과 팀 색 변경
- 플레이어 머리 잡기
- 눈사람 모드: 기존 PvP 맵을 재사용하되 줄어드는 환경 기믹 없이 10분 제한시간 동안 감염 승패를 진행한다.
- Steam 지원
- 콘솔·모바일 대응
- 추가 PvP 맵

## 기존 구현과 새 기획의 주요 변경점

- 기존 2~16명 목표를 최대 8명, 팀당 최대 4명으로 축소한다.
- 팀 직접 선택보다 서버 랜덤 배정을 먼저 구현한다.
- 맵 직접 선택을 제거하고 라운드마다 서버가 무작위로 선택한다.
- 기존 눈 쌓인 섬·얼음 동동 빙하·놀이터 구성을 얼음 빙하·눈섬·눈숲속으로 대체한다.
- 선물상자 공격 개봉을 근접 `E` 상호작용 개봉으로 바꾼다.
- 핫팩 부활 HP를 약 3분의 1에서 50%로 바꾸고 10초 진행과 3초 무적을 추가한다.
- 얼음 상태에 60초 제한을 두고 이후 해당 라운드 사망으로 전환한다.
- 패딩은 최대 HP 증가 대신 받는 피해 감소를 사용한다.
- 에너지 드링크는 상호작용 속도 증가 대신 5초 무적을 사용한다.
- 눈오리 제작기는 제작 속도 증가 대신 피해량 증가를 사용한다.
- 단일 라운드 승패에서 약 6분 소프트 목표의 3판 2선승 매치로 확장한다.
- 기존 MVP 이후 맵과 커스터마이징·아이템 확장 일부를 현재 MVP로 이동한다.

## 구현 전 확정이 필요한 세부 사항

- 같은 입력에 여러 행동이 겹칠 때의 정확한 우선순위
- 캐릭터 드로잉 입력, 저장과 복제 방식
- 얼굴 표정 선택과 드로잉 결과의 적용 우선순위
- 라운드별 랜덤 맵 중복 방지 방식
- 눈섬 자기장과 눈숲속 눈 폭의 피해·축소 단계 차이
- 큰 눈의 성장 기준, 최대 크기와 광역 피해 반경
- 붕어빵과 핫초코의 획득·사용 차이
- 신규 아이템의 상자 등급과 등급별 생성 확률·수량
- 황금 핫팩 사용 시 이미 사망한 팀원도 부활 가능한지
- 황금 아이템과 장비의 중복 획득 규칙
- 라운드 사이에 HP, 장비, 아이템과 맵 상태를 초기화하는 범위
- 6분 이후 환경 축소 속도와 최대 연장시간
- 방장이 나가거나 연결이 끊겼을 때의 처리

## 기획상 제외 또는 보류

- 얼음 상태의 플레이어를 추가 공격해 깨뜨리는 사망 규칙은 사용하지 않는다.
- 눈사람 모드와 머리 잡기는 현재 MVP에 포함하지 않는다. 눈사람 모드는 강혜원(K)이 추후 가능 시 개발할 후속 모드로 분리한다.
- 참고 이미지가 제공되지 않았으므로 캐릭터와 대기방 이미지는 이번 문서에 포함하지 않는다.
