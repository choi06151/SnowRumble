# SnowRumble GDD 진행 상태

## 현재 상태

- 프로젝트 버전: Prototype `v0.0.1`
- 기획 기준: `docs/GDD/Game_GDD.md`
- 현재 구현 상태: Unreal Engine 5.8 기본 프로젝트와 `SnowRumble` 런타임 모듈만 존재

## 확정된 기술 방향

- Listen Server
- OnlineSubsystem NULL
- LAN Session
- PC 우선 개발
- 2~16명 지원 목표, 4명 이상 권장

## MVP 목표

- LAN 멀티플레이 Host/Join
- 기본 캐릭터 이동, 카메라, 입력
- 눈 만들기
- 눈 줍기와 내려놓기
- 눈 조준과 충전 투척
- 눈 굴리기와 큰 눈
- HP, 피격, 얼기
- 같은 팀 관전과 핫팩 부활
- 선물상자
- MVP에 필요한 최소 아이템
- 기본 HUD
- 눈 쌓인 섬 맵
- 팀 전원 얼기 승패와 결과 화면

## MVP 단계

### Phase 1 — 프로젝트 기반과 2인 PIE

- 프로젝트 기준 점검
- 기본 캐릭터
- 카메라
- 입력
- Listen Server 호스트 1명과 클라이언트 1명의 PIE 이동 확인

### Phase 2 — 최소 네트워크 전투

- 서버가 생성하는 최소 눈덩이
- 눈덩이 생성·이동·충돌 복제
- HP와 피해
- 얼기

### Phase 3 — LAN 멀티플레이

- LAN Session
- Host/Join
- 대기방
- 팀 선택과 준비

### Phase 4 — 눈덩이 핵심 루프

- 눈덩이 생성
- 잡기와 내려놓기
- 조준, 충전, 투척
- 굴리기와 큰 눈

### Phase 5 — 전투 확장, 보상과 UI

- 아군 관전
- 핫팩 부활
- 선물상자
- MVP 기본 아이템
- HUD와 상호작용 표시

### Phase 6 — 경기 완성

- 눈 쌓인 섬
- 팀 승패
- 결과 화면
- 사운드와 MVP 검증

## MVP 이후

- 눈삽의 전체 등급·내구도 시스템
- 눈오리 제작기의 전체 등급 시스템
- 모든 착용 아이템의 외형 반영
- 이모션 선택 UI와 다양한 이모션
- 얼음 동동 빙하
- 놀이터
- 눈사람 만들기 모드
- Steam 지원
- 콘솔·모바일 대응
- 커스텀 룸

## 미결정 사항

- 같은 입력에 여러 행동이 겹칠 때의 정확한 우선순위
- 팀 수와 팀별 최대 인원
- 기본 HP, 눈덩이 피해량, 제작·충전 시간
- 큰 눈의 성장 기준, 최대 크기, 광역 피해
- 얼기 상태의 충돌과 파괴 가능 여부
- 선물상자 생성 주기, 수량, 등급 확률
- MVP에 포함할 기본 아이템의 정확한 목록
- 대기방과 게임 진행 맵 사이의 이동 방식
- 경기 제한시간과 무승부 규칙
- 황금 장비의 내구도 규칙
- 에너지 드링크 적용 범위와 지속시간

## 알려진 문제

- 아직 구현된 게임플레이 기능이 없어 실행 기반 문제는 확인되지 않았다.
