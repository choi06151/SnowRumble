# SnowRumble 게임 기획서

## 1. 프로젝트 개요

- 제목: `SnowRumble` (`눈싸움 대소동`)
- 장르: 3인칭 멀티플레이 파티 PvP
- 플랫폼: PC 우선, 콘솔·모바일 추후 대응
- 엔진: Unreal Engine 5.8
- 인원: 2~16명, 권장 4명 이상
- 네트워크: Listen Server, OnlineSubsystem NULL, LAN Session
- 기획 의도: 친구들과 부담 없이 즐길 수 있는 간단한 눈싸움 게임

## 2. 핵심 게임 규칙

눈이 쌓인 맵에서 눈덩이를 만들고 상대에게 던진다. 경기 중 생성되는 선물상자를 공격해 눈싸움에 도움이 되는 아이템을 얻을 수 있다. 피해를 받아 HP가 모두 소진된 플레이어는 얼어붙으며, 상대 팀의 모든 플레이어를 동시에 얼리면 승리한다.

### 핵심 게임 루프

1. 눈을 만들어 눈덩이를 준비한다.
2. 눈덩이를 줍거나 굴려 크기를 키운다.
3. 상대를 조준해 눈덩이를 던진다.
4. 선물상자를 공격해 아이템을 획득한다.
5. 아이템과 맵 환경을 활용해 상대 팀 전원을 얼린다.
6. 얼어붙은 아군은 핫팩으로 부활시킨다.

### PvP 목표

- 다른 팀 색상의 목도리를 착용한 플레이어 전원을 얼린다.
- 한 팀의 모든 플레이어가 동시에 얼면 해당 팀이 패배한다.

## 3. 기본 조작

| 입력 | 동작 |
| --- | --- |
| `WASD` | 이동 |
| 마우스 | 시점 조작 |
| `Left Shift` | 누르는 동안 스프린트 |
| 좌클릭 | 상황에 따라 눈 만들기, 눈덩이 던지기, 주먹 또는 장비 공격 |
| 우클릭 | 조준 |
| `E` | 물품 및 대상 상호작용 |
| `Space` | 점프 |
| `G` | 들고 있는 장비 내려놓기 |
| `Tab` | 이모션 선택 및 사용 |

같은 입력이 여러 동작에 사용될 때는 플레이어가 든 대상, 조준 여부, 카메라 방향, 상호작용 대상에 따라 현재 행동을 결정한다. 세부 우선순위는 구현 Task에서 사용자와 확정한다.

## 4. 플레이어 기능

### 4.1 눈덩이 만들기

- 카메라로 눈이 쌓인 바닥을 바라보고 좌클릭을 유지한다.
- MVP 프로토타입의 작은 눈덩이 제작시간은 `1.5초`다.
- 제작 게이지가 완료되면 작은 눈덩이가 만들어진다.

### 4.2 눈덩이 상호작용

- 플레이어가 바닥의 눈덩이에 가까워지면 아웃라인과 상호작용 UI가 표시된다.
- 선택 가능한 행동은 `잡기`와 `굴리기`다.
- 이동 입력 없이 `E`를 눌렀다 놓으면 눈덩이를 든다.
- `E`를 누른 시점부터 눈덩이로 손을 뻗는 동작이 시작된다.

### 4.3 작은 눈덩이 조준과 투척

- 눈덩이를 든 상태에서 우클릭을 유지하면 투척 자세로 조준한다.
- 조준 중 캐릭터 몸은 카메라가 바라보는 수평 방향을 향하며 이동 입력에는 스트레이프로 반응한다.
- 조준 중에는 카메라 FOV가 약간 좁아지고 이동속도가 느려지며, 스프린트 입력으로 속도를 높일 수 없다.
- 눈덩이는 조준 상태일 때만 던질 수 있다.
- 조준 중 좌클릭을 유지하면 투척 게이지가 충전된다.
- 좌클릭을 놓으면 충전량에 비례한 힘으로 화면 중앙 방향에 눈덩이를 던진다.
- 작은 눈덩이는 야구공처럼 빠르게 날아가며 눈덩이 크기만큼의 충돌 범위를 가진다.
- 날아가는 눈덩이는 플레이어에게 피해를 주거나 선물상자를 개봉할 수 있다.

### 4.4 눈덩이 굴리기

- 눈덩이 앞에서 `E`를 유지하며 이동하면 획득 대신 눈덩이를 굴린다.
- `E`를 놓으면 굴리기를 종료한다.
- 굴린 거리나 시간에 따라 눈덩이가 최대 크기까지 커진다.
- 눈덩이가 커질수록 플레이어 이동속도가 감소한다.

### 4.5 큰 눈덩이 운반과 투척

- 큰 눈덩이는 양손으로 들며 작은 눈덩이보다 운반 속도가 느리다.
- 투척 게이지 충전 시간도 더 길다.
- 큰 눈덩이는 농구공처럼 포물선을 그리며 날아간다.
- 충돌하면 터지면서 주변 넓은 범위에 피해를 준다.

### 4.6 맨손 방해

- 손에 눈덩이나 장비가 없을 때 좌클릭하면 손을 가볍게 휘두른다.
- 적중한 상대를 방해할 수 있으며, 정확한 밀침·경직 효과는 구현 전에 확정한다.

### 4.7 얼기와 관전

- HP가 모두 소진되면 플레이어가 얼어붙는다.
- 얼어붙은 플레이어는 단단한 오브젝트처럼 눈덩이를 막는 엄폐물이 된다.
- 얼어있는 동안 같은 팀 생존 플레이어의 화면을 관전한다.

### 4.8 핫팩 부활

- 핫팩을 가진 플레이어는 얼어붙은 아군에게 상호작용해 부활시킬 수 있다.
- 부활하면 최대 HP의 약 3분의 1을 회복한다.
- 부활에 사용한 핫팩은 소모된다.

### 4.9 이모션

- `Tab`을 통해 여러 이모션을 선택하고 사용한다.
- 이모션은 놀이와 감정 표현을 위한 기능이며 전투 효과는 없다.

## 5. 아이템 원칙

- 일반적인 인벤토리는 사용하지 않는다.
- 아이템은 획득 즉시 사용하는 `사용형` 또는 캐릭터에 반영되는 `착용·장비형`으로 구분한다.
- 장비형 아이템 중 내려놓을 수 있는 대상은 `G`를 사용한다.
- 부츠, 장갑, 패딩 같은 장비는 플레이어 외형에도 반영한다.

## 6. 선물상자

- 일정 시간마다 산타가 흘린 선물상자가 맵의 무작위 위치에 생성된다.
- 플레이어에게 피해를 줄 수 있는 공격이 상자에 적중하면 상자가 개봉된다.
- 등급은 파랑, 빨강, 금색 순으로 높아지며 외관과 등장 아이템이 달라진다.

| 등급 | 등장 후보 |
| --- | --- |
| 파랑 | 핫초코, 에너지 드링크 |
| 빨강 | 부츠, 패딩, 장갑, 녹슨 눈삽, 녹슨 눈오리 제작기 |
| 금색 | 핫팩, 황금 눈삽, 황금 눈오리 제작기, 모닥불 키트 |

등급별 확률과 한 경기의 생성 수량은 아직 정하지 않는다.

## 7. 아이템

### 핫팩

- 플레이어의 뒷주머니에 장착된다.
- 얼어붙은 아군 한 명을 부활시킨다.

### 눈삽

- 근거리의 넓은 범위를 공격하는 장비다.
- 기본 좌클릭은 눈삽으로 앞을 밀쳐 상대를 약간 밀어낸다.
- 땅을 보며 눈을 파서 장전하는 동안 이동속도가 더 느려진다.
- 장전 후 바라보는 방향으로 눈을 흩뿌려 넓은 범위에 피해를 준다.
- 녹슨 눈삽은 2~4 사이의 무작위 내구도를 가지며 발사할 때마다 내구도가 감소한다.
- 황금 눈삽의 내구도 규칙은 추후 확정한다.
- 공격받더라도 자동으로 떨어뜨리지 않으며 `G`로 내려놓는다.

### 눈오리 제작기

- 기존 방식보다 눈 투사체 제작 속도를 크게 높이는 장비다.
- 녹슨 등급과 황금 등급의 차이는 추후 확정한다.

### 부츠

- 이동속도를 증가시키고 외형에 반영한다.

### 패딩

- 최대 HP를 증가시키고 외형에 반영한다.

### 장갑

- 눈 제작 속도를 증가시키고 외형에 반영한다.

### 핫초코

- 획득 즉시 HP를 회복한다.

### 에너지 드링크

- 일정 범위의 상호작용 게이지 충전 속도를 증가시킨다.
- 적용 대상과 지속시간은 추후 확정한다.

### 모닥불 키트

- 선물상자가 개봉된 위치에 작은 모닥불을 즉시 설치한다.
- 모닥불 주변의 모든 플레이어는 팀과 무관하게 HP를 회복한다.
- 눈덩이에 맞으면 모닥불이 꺼진다.

## 8. 맵 공통 오브젝트

- 눈덩이: 바로 주워 사용할 수 있는 기본 눈덩이
- 눈사람: 플레이어가 굴려 만든 큰 눈덩이와 유사한 상호작용 대상
- 모닥불: 팀과 무관하게 주변 플레이어를 회복시키며 눈덩이에 맞으면 꺼지는 오브젝트
- 얼음물: 플레이 가능 영역을 제한하며 접촉한 플레이어에게 지속 피해를 주는 환경 요소
- 얼음물에 빠진 플레이어는 짧은 시간 수영해 안전한 위치로 이동할 수 있다.

## 9. 레벨 흐름

### 최초 접속 로비

- 호스트 생성
- 호스트 참가
- 옵션
- 게임 종료

### 게임 대기방

- 플레이어 이름 설정
- 팀 색상 설정
- 캐릭터 외형 설정
- 준비 및 준비 해제
- 게임 모드 선택
- 게임 모드 세부 설정

### 게임 진행 방

- 선택된 게임 모드에 맞는 맵에서 경기를 진행한다.
- 정확한 랜덤 맵 선택 방식과 이동 방식은 추후 확정한다.

## 10. 게임 모드

### PvP

- 현재 우선 개발하는 게임 모드다.
- 상대 팀 전원을 동시에 얼리는 것이 목표다.

### 눈사람 만들기

- 장기 확장용 게임 모드이며 현재 MVP에는 포함하지 않는다.

## 11. 플레이어 외형

- 귀엽고 둥근 Gang Beasts 계열의 실루엣을 지향한다.
- 목도리 색상으로 팀을 구분한다.
- 정면의 표정은 대기방에서 변경할 수 있다.
- 부츠, 장갑, 패딩을 획득하면 팔·다리·몸통 외형에 반영한다.

특정 상용 게임의 자산이나 디자인을 그대로 복제하지 않고 분위기와 가독성만 참고한다.

## 12. PvP 맵

### 눈 쌓인 섬

- 현재 MVP의 우선 맵이다.
- 작은 눈 섬 주변을 얼음물이 둘러싼다.
- 시간이 지날수록 수위가 올라 플레이 가능 영역이 줄어든다.
- 물에 닿은 플레이어는 피해를 받는다.

### 얼음 동동 빙하

- 넓은 물 위의 여러 빙하에서 전투한다.
- 바닥은 미끄럽다.
- 어떤 플레이어든 같은 빙하를 밟은 누적 시간이 기준에 도달하면 해당 빙하가 물에 잠겨 사라진다.
- 현재 제안 기준은 누적 10초이며 밸런스 조정 대상이다.

### 놀이터

- 미끄럼틀과 그네 등이 있는 매우 작은 사각형 맵이다.
- 별도의 시간 압박보다 좁은 공간에서 발생하는 근접 전투가 특징이다.

## 13. 현재 기술 방향

- 최초 네트워크 프로토타입은 Listen Server로 구성한다.
- OnlineSubsystem NULL과 LAN Session으로 Host/Join 흐름을 우선 검증한다.
- Steam, 콘솔, 모바일 온라인 기능은 현재 MVP 이후에 검토한다.

- 눈사람 만들기 게임 모드
